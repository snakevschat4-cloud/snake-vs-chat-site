Privacy Policy

Effective date: October 27, 2026

In short: Snake vs Chat uses the YouTube API Services to read the public chat messages and the like count of its own live stream. When you type a game command, your YouTube display name may appear on the stream. We do not sell or share your information, and we do not ask you to sign in.

Who we are

Snake vs Chat is an interactive game broadcast on the YouTube channel @snakevschat. The game is run by the channel owner, who can be contacted at snakevschat4@gmail.com.

Use of YouTube API Services

The Snake vs Chat app uses the YouTube API Services. By interacting with the live stream you also agree to the YouTube Terms of Service, and your information on YouTube is handled under the Google Privacy Policy.

Information the app accesses

The app is authorized only by the channel owner, with read-only access to the channel's own YouTube account. Through that access it reads:

  • which live stream of the channel is currently active;
  • messages posted in that live chat: the text, the time it was sent, the author's YouTube display name and channel ID, and Super Chat, Super Sticker and new member events with their displayed amount;
  • the number of likes on the live stream.

Viewers never sign in to the app, and the app does not access any viewer's account, email address, subscriptions or watch history.

How the information is used

  • On the stream: when a chat message contains a game command (such as fruit or a country code like !br), the game reacts to it and may show the author's display name on screen, for example next to the fruit or in the round's ranking.
  • Country scoreboard: country commands add one point to that country's total. Only the total per country is kept, with no names attached.
  • Like goal: the like count is used to trigger the fruit rain.

What is stored, and for how long

  • The number of games won and the per-country point totals are saved on the computer that runs the game, so the scoreboard survives a restart. These contain no personal information.
  • The round ranking (display names and fruits dropped) is kept in memory only and is discarded when the next round starts or the game restarts.
  • A technical log on the same computer records game commands with the author's display name and arrival time, used only to fix problems. It is not shared and is periodically deleted.

Chat messages themselves remain stored by YouTube under its own policies.

Sharing

We do not sell, rent or share information read through the YouTube API Services with anyone. The only place it appears is the live stream itself, as described above.

Cookies and third parties

The Snake vs Chat app does not place cookies or collect information on viewers' devices. The live stream is watched on YouTube, where YouTube and Google may serve content, including ads, and use cookies under their own policies. This website is hosted on GitHub Pages, which may keep technical logs such as IP addresses, as described in GitHub's privacy statement.

Revoking access and deleting data

Only the channel owner authorizes the app. That authorization can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions.

If you would like your display name removed from the game's log, or have any privacy question or complaint, email snakevschat4@gmail.com.

Changes

If this policy changes, the new version will be published on this page with a new effective date.
