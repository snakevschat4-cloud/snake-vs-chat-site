SNAKE vs CHAT

A snake AI that plays forever on YouTube Live — and the chat drops the fruit.

How to play

  • Type fruit (or fruta) in the live chat to drop a fruit with your name on it.
  • Type !br, !us, !kr… to score a point for your country.
  • Every 50 likes on the live stream triggers a fruit rain.
  • A Super Chat drops a golden apple with your name on screen.

Watch

Live on YouTube: youtube.com/@snakevschat

About this app

Snake vs Chat is a program run by the channel owner. It uses the YouTube API Services to read the channel's own live chat and like count, so the game can react to viewers. It does not ask viewers to sign in, and it never posts, edits or deletes anything on anyone's account.
